## 建议复习路径

1. 先掌握“指导与管理项目工作”的 ITTO 与会议，再串起“工作绩效数据→信息→报告”和可交付成果流转。
2. 沿“管理质量 → 工具与技术 → 审计与改进”学习质量主线。
3. 集中对比获取资源、建设团队、管理团队三过程，再记塔克曼五阶段与冲突解决方法。
4. 记忆沟通、风险应对、采购、干系人参与各自的作用与关键输出（问题日志、变更请求、采购文档、选定卖方）。

## 易混边界

- **规划过程组 / 执行过程组**：前者产出计划与基准，后者把计划变成可交付成果。
- **管理质量 / 控制质量**：管理质量重过程改进与质量绩效；问题解决针对控制质量或质量审计发现的问题。
- **获取资源 / 建设团队 / 管理团队**：获取=得到资源，建设=提升能力协作，管理=跟踪表现处理冲突。
- **建设团队 / 管理团队中的冲突处理**：建设团队以建设性方式管理冲突；管理团队给出五种具体解决方法。
- **工作绩效数据 / 信息 / 报告**：执行产生数据，控制过程分析成信息，监控项目工作汇总成报告。
- **管理质量 / 控制质量**：除过程改进与成果正确性的区别外，原稿关系图还以“变更是否实施 / 是否实施正确”辨识二者（待教材核对）。
- **风险规划 / 实施风险应对**：规划定义如何管理风险，实施按计划执行商定应对。
- **实施采购 / 规划采购**：实施=选定卖方并签约；规划=确定采购策略与文档（本章未覆盖规划采购）。
