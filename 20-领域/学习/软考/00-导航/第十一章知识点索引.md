## 建议复习路径

1. 先看项目管理计划与范围管理，理解规划过程组如何从目标落到范围基准。
2. 沿 `WBS → 活动 → 排序 → 估算 → 进度计划` 学习进度主线。
3. 集中练习关键路径、总浮动和自由浮动公式，再对比资源优化与进度压缩。
4. 依次记忆成本、质量、资源和沟通计划中的高频输出与分类。
5. 按 `规划风险管理 → 识别风险 → 定性分析` 复习风险主线。

## 易混边界

- **章程 / 项目管理计划**：前者授权，后者说明怎么做。
- **WBS / 活动清单**：前者面向可交付成果，后者记录具体行动。
- **PDM / ADM**：PDM 节点表示活动；ADM 箭线表示活动。
- **资源平衡 / 资源平滑**：平衡可能改变关键路径，平滑不改变。
- **赶工 / 快速跟进**：赶工加资源，快速跟进改并行。
- **成本基准 / 项目预算**：成本基准不含管理储备。
- **风险登记册 / 风险报告**：单个风险明细与整体风险概况。
