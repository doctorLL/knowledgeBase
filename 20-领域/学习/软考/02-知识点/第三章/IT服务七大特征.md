# IT 服务七大特征

## 卡片速览

IT 服务除具备服务的基本特征外，还具备 7 项特征：**本质、形态、过程、阶段、效益、内部关联性、外部关联性**。

## 记忆要点

- **本质特征**：组成要素是人员、过程、技术和资源；由具备匹配知识、技能和经验的人员，合理运用资源，通过规定过程向需方提供 IT 服务。
- **形态特征**：IT 咨询服务、设计与开发服务、信息系统集成服务、数据处理和运营服务、智能化服务及其他 IT 服务。
- **过程特征**：从项目级、组织级、量化管理级、数字化运营逐步发展；从计算机单机应用、网络应用、综合管理逐步提升，具有连续不断和可持续发展的特征。
- **阶段特征**：IT 发展永无止境，IT 服务也无终极目标；需分层次、分阶段推进。
- **效益特征**：不同于产品技术改造（效果往往单方面、容易显现），IT 服务是从整体上提高组织核心竞争力和管理水平，**效益是多方面的**。
- **内部关联性特征**：IT 服务**不仅依赖于技术创新，更依赖于业务模式创新**；保持技术创新和业务模式创新的相互促进、有机融合，实现人才结构优化，建立 IT 服务管理规范。
- **外部关联性特征**：依赖国民经济和良性竞争的市场环境、社会信息网络的进步、政府政策支撑、配套人才的培养以及产业链上下游组织 IT 应用的完善。

## 口诀

**本形过阶效，内关外关**（本质—形态—过程—阶段—效益—内部关联性—外部关联性，共 7 项）。

## 判据（抓题干关键词）

| 题干关键词 | 答案 |
|---|---|
| 人员/过程/技术/资源四要素、按过程向需方交付 | 本质特征 |
| 列举咨询、设计开发、集成、数据处理运营等服务种类 | 形态特征 |
| 项目级→组织级→量化管理级→数字化运营、持续发展 | 过程特征 |
| 无终极目标、分层次分阶段推进 | 阶段特征 |
| 效益多方面的、整体提升核心竞争力 | 效益特征 |
| **技术创新 + 业务模式创新（更依赖后者）** | **内部关联性特征** |
| 国民经济、市场环境、政策支撑、产业链上下游 | 外部关联性特征 |

## 自测

> [!question]- "IT 服务不仅依赖于技术创新，更依赖于业务模式创新"体现的是哪一项特征？
> 内部关联性特征。（第 3 批第 44 题原题）

> [!question]- 七大特征是哪七项？
> 本质、形态、过程、阶段、效益、内部关联性、外部关联性。
