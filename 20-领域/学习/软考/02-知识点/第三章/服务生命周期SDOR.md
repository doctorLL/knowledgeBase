# 服务生命周期SDOR

## 卡片速览

**服务生命周期SDOR**：战略规划 → 设计实现 → 运营提升 → 退役终止；监督提供保障，管理提供支撑。

## 记忆要点

- 战略规划从业务战略出发，以需求为中心，是 IT 服务发展和能力体系建设的首要之事。
- 设计实现形成体系结构、解决方案部署、专用工具与管理体系。
- 运营提升随业务需求和市场变化优化流程、提升能力；终止服务需要书面计划。
- SDOR 的对象是 IT 服务，不与信息系统生命周期的阶段划分直接等同。
