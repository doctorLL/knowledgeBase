# SSC三种模式

## 卡片速览

**SSC三种模式**：按原稿，模式 1 保持会话 IP 接入点，模式 2 先释放后新建，模式 3 先新建后释放。

## 记忆要点

- 模式 1：用户移动过程中会话 IP 接入点始终不变。
- 模式 2：网络触发现有会话释放，随后触发新会话建立。
- 模式 3：释放旧会话前先建立新会话；原稿关联对中断敏感的业务。
- 本卡按原稿比较新旧会话衔接顺序，不额外宣称任何模式保证绝对零中断。

> [!question]- 模式 2 和模式 3 最容易混淆的差别是什么？
> 旧会话释放与新会话建立的先后顺序。
