# 完工估算与完工尚需绩效指数

## 记忆要点

- 通式：`EAC = AC + ETC`。
- 非典型偏差：`ETC = BAC - EV`。
- 典型偏差：`ETC = (BAC - EV) / CPI`，或 `EAC = BAC / CPI`。
- TCPI 表示剩余资源必须达到的成本绩效；原稿给出以 BAC 为目标时：`TCPI = (BAC - EV) / (BAC - AC)`。

## 自测

> [!question]- 典型与非典型偏差下 ETC 如何计算？
> 非典型：`BAC-EV`；典型：`(BAC-EV)/CPI`。
