# 项目管理十二项原则

## 卡片速览

项目管理原则共 **12 条**：勤勉尊重关心他人、营造协作团队环境、促进干系人参与、聚焦于价值、识别评估响应系统交互、展现领导力行为、根据环境裁剪、将质量融入过程与成果、驾驭复杂性、优化风险应对、拥抱适应性和韧性、为实现目标驱动变革。

## 记忆要点

| # | 原则 |
|---|---|
| 1 | 勤勉、尊重和关心他人 |
| 2 | 营造协作的项目管理团队环境 |
| 3 | 促进干系人有效参与 |
| 4 | 聚焦于价值 |
| 5 | 识别、评估和响应系统交互 |
| 6 | 展现领导力行为 |
| 7 | 根据环境进行裁剪 |
| 8 | 将质量融入到过程和成果中 |
| 9 | 驾驭复杂性 |
| 10 | 优化风险应对 |
| 11 | 拥抱适应性和韧性 |
| 12 | 为实现目标而驱动变革 |

## 口诀

**勤协与价 / 系领裁质 / 复险韧变**（12 字对 12 条：勤勉尊重—协作团队—促进参与—聚焦价值 / 系统交互—领导力—裁剪—质量 / 复杂性—风险应对—韧性—驱动变革）。

## 易错点

- **"聚焦人才培养"不是项目管理原则**（第 3 批第 43 题的干扰项）；容易与第 ④ 条"聚焦于价值"、第 ⑫ 条"驱动变革"混淆。
- 第 ① 条是"勤勉、**尊重和关心他人**"（三个词一起记），不是"尊重他人"一条。
- 别与管理要素、项目经理职责、PMI 道德价值观（责任、尊重、公正、诚实）混为一谈——那是另一套清单。

## 自测

> [!question]- 下列哪项不属于项目管理原则：驾驭复杂性 / 展现领导力行为 / 聚焦人才培养 / 拥抱适应性和韧性？
> 聚焦人才培养。其余三项均在 12 条内。

> [!question]- 12 条原则中与"环境/裁剪"相关的是哪一条？
> ⑦根据环境进行裁剪。
