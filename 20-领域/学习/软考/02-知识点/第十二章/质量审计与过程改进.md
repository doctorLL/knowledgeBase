# 质量审计与过程改进

## 卡片速览

**质量审计目标、问题解决的结构化方法、质量改进方法与面向 X 设计**的辨识要点。

## 记忆要点

- 质量审计目标：识别良好/最佳实践；识别违规、差距与不足；分享类似项目良好实践；积极协助改进过程执行、提高生产效率；强调对组织经验教训知识库作出积极贡献。
- 问题解决：结构化方法，从定义问题、识别根本原因，到形成备选方案、选择最好的方案，再到实施、核实解决效果。
- 质量改进方法：戴明环、六西格玛、精益生产、精益六西格玛。
- 面向 X 的设计（DfX）：X 既可是“卓越”，也可是可靠性、可用性、安全性、经济性等产品特性。
