# 冲突解决方法

## 卡片速览

**五种冲突解决方法**及其输赢/双赢结果的辨识。

## 记忆要点

| 方法 | 效果 |
|---|---|
| 撤退/回避 | 暂缓或回避冲突 |
| 缓和/包容 | 强调共识、淡化分歧 |
| 妥协/调解 | 各方让步、部分满足 |
| 强迫/命令 | 以权力强行解决，导致输赢局面 |
| 合作/解决问题 | 综合各方观点，导致双赢局面 |

## 自测

> [!question]- 哪种冲突解决方法导致双赢、哪种导致输赢？
> 合作/解决问题导致双赢；强迫/命令导致输赢。
