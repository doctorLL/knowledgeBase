## 状态怎么用

| 属性 | 规则 |
|---|---|
| 掌握程度 | 未学 / 理解 / 易错 / 掌握；初始全部为未学，不推测实际水平。 |
| 核对状态 | 已按原稿整理 / 待教材核对 / 已核验教材；已按原稿整理包含沿用现有正文勘误，不等于本次重新查证。 |
| 最近复习 | 初始留空，复习后手动填写日期，例如 `2026-08-31`。 |
| 待复习视图 | 收录尚未标为“掌握”的卡片，不自动安排复习日期。 |

“已核验教材”只在取得教材依据、记录版次页码后设置。初始有 **7 张待核对卡片**：信息特征、系统特征、信息系统生命周期、信息化、智能制造、服务现代化、智慧城市；疑点见各卡片“核对边界”。

既有正文对部分标准或资料已有历史核对记录，本次只提炼与链接，不重新确认其当前版本状态。不要因为自测答对就把核对状态改成“已核验教材”。

## 使用和维护

1. 从卡片“速览”开始，先独立回答折叠自测，再查看答案。
2. 沿“对比、包含、支撑、阶段、跨章展开”等关系继续阅读；需要完整解释时回到正文小节。
3. 更新掌握程度和最近复习日期；真实错题写入 [[03-错题库/错题库#第一章 信息化发展|第一章错题库]]，关联对应卡片，不生成虚构错题。
4. 新卡片使用 [[90-模板/知识点卡片模板|知识点卡片模板]]，放入 `02-知识点/第一章/`，所属章节填“第一章”，编号使用未占用的 CH01-xx。
5. 管理表自动汇总卡片属性；Canvas 已有节点随卡片速览文字更新，新增卡片或改变关系时需同步节点与连线。分组颜色表示主题，不表示掌握程度。
6. 正文修改后检查相应卡片的速记与自测，原稿不搬走、不删除。
