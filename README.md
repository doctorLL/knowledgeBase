# knowledgeBase

个人 Obsidian 总知识库，用于记录技术、生活、学习、项目和参考资料。

## 使用方式

1. 在 Obsidian 中选择“打开本地仓库”。
2. 选择本仓库根目录作为 Vault。
3. 从 `知识库首页.md` 开始浏览。
4. 新笔记默认进入 `00-收件箱`，整理时再移动到项目、领域或资料库。

## 目录约定

- `00-收件箱`：暂未分类的随手记录。
- `10-项目`：有明确目标和结束时间的内容。
- `20-领域`：技术、生活、学习等长期积累。
- `30-资料库`：书籍、文章和外部参考资料。
- `90-模板`：全库共用模板。
- `98-归档`：已经结束、不再活跃的内容。
- `99-附件`：全库共用附件。

文件夹负责稳定分类，链接负责知识关系，标签只表达状态或横向属性。一个主题积累到 3～5 篇笔记后再建立子目录。

`.obsidian/workspace.json` 等设备相关界面状态不会纳入 Git；附件目录、核心插件设置和知识库结构会正常同步。
