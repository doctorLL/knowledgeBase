# 云原生架构模式

## 卡片速览

**云原生架构模式**：服务化、Mesh 化、Serverless、存储计算分离、分布式事务、可观测、事件驱动七类模式。

## 记忆要点

- 服务化：原稿典型为微服务、小服务；EDA 是应用或组件之间的集成架构模式。
- Mesh 化：把 RPC、缓存等中间件框架从业务进程中分离，使中间件 SDK 与业务代码进一步解耦。
- 可观测：Logging 日志、Tracing 追踪、Metrics 度量。
- Serverless 与存储计算分离原稿仅列名称，本卡保留入口，不自行补造完整定义或另建空卡。
