# 5G互联与边缘计算

## 卡片速览

**5G互联与边缘计算**：原稿从 5GS 与 DN 互联及边缘计算两方面展开，重点记 N6、上下行、接入方式和分流角色。

## 记忆要点

- 按原稿：5GS 与 DN 通过 N6 互连；UE→DN 为上行 UL，DN→UE 为下行 DL。
- 透明模式：UE 使用运营商规划 IP；非透明模式：SMF 经 DN-AAA 完成 UE 认证。
- 边缘侧部署 UPF，SMF 动态配置 UPF 分流规则；原稿以 AF、NEF、PCF、SMF 描述策略触发与配置。
- 原稿“需要 SDN 网络”“边缘计算平台 MEF”等术语仅留作核对线索，不据此推导 5G 必须采用某个 SDN 方案。

> [!question]- 原稿如何定义 UL 和 DL？谁配置 UPF 分流规则？
