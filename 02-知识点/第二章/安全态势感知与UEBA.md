# 安全态势感知与UEBA

## 卡片速览

**安全态势感知与UEBA**：态势感知基于安全大数据形成网络整体态势；UEBA 的原稿场景是内部人员窃取敏感数据的隐蔽行为。

## 记忆要点

- 态势感知：数据整合、特征提取、态势评估算法。原稿另列汇聚融合、威胁评估、评估与决策支撑、可视化四类技术。
- UEBA 原稿层次：数据源 → 采集与接入 → 处理与标准化 → 存储与计算 → 用户与实体画像 → 行为分析与监测 → 风险评分与应用。
- APT 的原稿关键词是长期潜伏、多阶段渗透；它是威胁描述，不是与 UEBA 并列的防御工具。
- 原稿还将 IDS 特征检测与自动化蠕虫攻击场景关联；仅保留该例，不扩写通用检测能力。
