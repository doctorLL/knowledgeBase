# WBS定义与分解步骤

## 卡片速览

WBS 是项目全部工作范围面向可交付成果的层级分解，最底层为工作包。

## 记忆要点

- “工作”指工作产品或可交付成果，不是活动动作。
- 步骤：识别成果 → 确定结构 → 自上而下分解 → 编码 → 核实程度。
- 创建 WBS 的作用是为所要交付的内容提供架构。
